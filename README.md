# ABG NSSKRU Web App

เว็บแอปสำหรับฝึกแปลผล Arterial Blood Gas (ABG) เชื่อมโยงการพยาบาล และเกมฝึก GBL

## โครงสร้างโฟลเดอร์

```text
my-webapp/
├── index.html
├── css/
│   ├── style.css
│   ├── responsive.css
│   └── components.css
├── js/
│   ├── app.js
│   ├── auth.js
│   └── functions.js
├── pages/
│   ├── dashboard.html
│   ├── login.html
│   └── settings.html
├── assets/
│   ├── images/
│   └── icons/
└── README.md
```

## วิธีเปิดใช้งาน

1. แตกไฟล์ ZIP
2. เปิด `index.html` ผ่านเว็บเบราว์เซอร์ หรือแนะนำให้รันผ่าน Live Server
3. หน้า `pages/login.html` และ `pages/dashboard.html` เป็นทางลัดเข้าสู่หน้าที่เกี่ยวข้องในแอปหลัก

## หมายเหตุการแยกไฟล์

- `css/style.css` เก็บตัวแปรสี ฟอนต์ และสไตล์พื้นฐาน
- `css/components.css` เก็บสไตล์องค์ประกอบและส่วนต่าง ๆ ของแอป
- `css/responsive.css` เก็บกฎ `@media` สำหรับหน้าจอขนาดต่าง ๆ
- `js/app.js` เก็บตรรกะหลักของแอปเดิมไว้ครบ เพื่อรักษาการทำงานและการใช้สถานะร่วมกัน
- `js/auth.js` จัดการทางเข้าหน้าเข้าสู่ระบบ ส่วนตรรกะยืนยันตัวตนเดิมยังอยู่ใน `app.js` เพราะเชื่อมโยงกับข้อมูลผู้เล่นและระบบจัดเก็บ
- `js/functions.js` มีฟังก์ชันนำทางไปยังแท็บต่าง ๆ
- `pages/settings.html` เป็นหน้าเริ่มต้นสำหรับพัฒนาระบบตั้งค่า เนื่องจากไฟล์ต้นฉบับยังไม่มีหน้าตั้งค่าแยก

ภาพตัวการ์ตูนบางส่วนฝังเป็น Data URI อยู่ใน `js/app.js` ของต้นฉบับ จึงยังไม่แยกออกเป็นไฟล์ภาพ เพื่อไม่ให้ภาพหรือแอนิเมชันเดิมเสียหาย
